### **开发任务清单 (DEV_TASKS)**

**Phase 1: 项目基础与架构搭建**

*   **任务 1: 初始化项目结构与依赖**
    *   1.1: 确定并添加核心第三方依赖到 `pubspec.yaml` (例如: `flutter_riverpod` 用于状态管理, `dio` 用于网络请求, `just_audio` 用于音频播放, `isar` 用于本地数据库)。
    *   1.2: 创建清晰的目录结构 (`lib/src/core`, `lib/src/features`, `lib/src/shared`)。
    *   1.3: 设置基础的 `main.dart`，初始化Riverpod的 `ProviderScope`。

*   **任务 2: UI基础框架与主题**
    *   2.1: 创建App的整体UI Shell，包含一个带有底部导航栏 (`BottomNavigationBar`) 的主屏幕。
    *   2.2: 定义应用的色彩方案 (`ColorScheme`) 和主题 (`ThemeData`)，以符合“现代简约、有高级感”的要求（包括亮色和暗色主题）。
    *   2.3: 设置底部导航栏的三个主要页面：首页 (Home)、搜索 (Search)、我的音乐 (Library)。

**Phase 2: 核心功能开发 (MVP)**

*   **任务 3: 后端API与数据模型**
    *   3.1: 根据后端规范，创建Dart数据模型 (`Song`, `Playlist`, `Artist` 等)。
    *   3.2: 创建一个API服务类 (e.g., `ApiService`)，使用 `dio` 封装网络请求。
    *   3.3: **(关键)** 创建一个音乐仓库 (`MusicRepository`)，它将作为UI层和数据层之间的桥梁。初期可以先用**模拟数据 (Mock Data)** 实现，以便UI开发可以先行。
    *   3.4 已有后端接口，接口格式为
        ```
        curl --location 'http://216.24.179.28:8001/music/search' \
        --header 'Content-Type: application/json' \
        --header 'Authorization: Bearer 123567' \
        --data '{
            "keyword":"枫"
        }'
        ```
        keyword为搜索关键词

*   **任务 4: 搜索功能**
    *   4.1: 开发搜索页面UI，包含一个搜索输入框和用于展示结果的列表。
    *   4.2: 将UI与 `MusicRepository` 连接，实现根据关键词调用搜索接口并展示返回的歌曲列表。

*   **任务 5: 音乐播放器**
    *   5.1: 使用 `just_audio` 实现核心的音频播放逻辑（播放、暂停、停止、跳转）。
    *   5.2: 创建一个全屏的播放器UI，展示歌曲封面、歌曲信息、播放控制按钮和进度条。
    *   5.3: 实现播放队列管理。
    *   5.4: 开发歌词展示UI，并实现歌词与播放进度的同步。

*   **任务 6: 本地收藏功能 ("我的喜欢")**
    *   6.1: 使用 `isar` 初始化本地数据库，并创建 `FavoriteSong` 数据表。
    *   6.2: 在播放器和歌曲列表项中添加“喜欢”按钮。
    *   6.3: 实现将歌曲添加到“我的喜欢”列表以及从列表中移除的功能。
    *   6.4: 在“我的音乐”页面中，创建一个能展示所有已收藏歌曲的列表。

**Phase 3: 完善与扩展 (V1.1)**

*   **任务 7: 音乐推荐**
    *   7.1: 对接真实的网易云音乐API或解析离线数据，获取推荐歌单和歌曲。
    *   7.2: 在“首页”上开发UI组件，用于展示推荐内容。

*   **任务 8: 完整的歌单管理**
    *   8.1: 允许用户创建、重命名和删除自己的歌单。
    *   8.2: 实现将任意歌曲添加到指定歌单的功能。

**Phase 4: 打磨与测试**

*   **任务 9: 平台适配与优化**
    *   9.1: 针对Android、iOS和macOS分别进行UI和体验的微调。
    *   9.2: 处理各平台的权限请求（如网络权限）。

*   **任务 10: 编写测试**
    *   10.1: 为核心逻辑（如 `MusicRepository`, 状态管理逻辑）编写单元测试。
    *   10.2: 为关键UI页面（如播放器、搜索页）编写Widget测试。
